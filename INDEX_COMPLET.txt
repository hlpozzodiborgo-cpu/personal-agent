## 🔧 BACKEND - FICHIERS DÉTAIL

### **main.py** (220+ lignes)
**Rôle:** Application FastAPI principale

**Contient:**
- Configuration FastAPI
- Routes API (15+ endpoints)
- Dépendances (get_db)
- Middleware CORS

**Routes principales:**
```
GET    /health                             # Health check
GET    /api/assets                         # Lister actifs
POST   /api/assets/add                     # Ajouter actif
GET    /api/assets/{symbol}/info           # Infos actif
GET    /api/assets/{symbol}/history        # Historique prix
GET    /api/portfolio                      # Vue portefeuille
POST   /api/holdings/add                   # Ajouter position
DELETE /api/holdings/{holding_id}          # Supprimer position
```

### **models.py** (140+ lignes)
**Rôle:** Modèles SQLAlchemy pour base de données

**Tables créées:**
- `Asset` - Actifs à suivre (AAPL, BTC, etc.)
- `Holding` - Positions du portefeuille
- `Transaction` - Historique achat/vente
- `PriceHistory` - Historique des prix
- `PortfolioSnapshot` - Snapshots du portefeuille

**Relations:** Holding → Asset, Transaction → Holding

### **crud.py** (170+ lignes)
**Rôle:** Opérations CRUD (Create, Read, Update, Delete)

**Classes:**
- `AssetCRUD` - Opérations sur actifs
- `HoldingCRUD` - Opérations sur positions
- `TransactionCRUD` - Opérations sur transactions
- `PriceHistoryCRUD` - Opérations sur historique

**Exemple:**
```python
holding = HoldingCRUD.create(db, asset_id=1, quantity=10, avg_price=143.50)
holdings = HoldingCRUD.get_all_active(db)
TransactionCRUD.create(db, holding_id=1, transaction_type="buy", quantity=10, price_per_unit=143.50)
```

### **schemas.py** (100+ lignes)
**Rôle:** Validation des données avec Pydantic

**Schemas:**
- `AssetBase`, `AssetCreate`, `Asset`
- `HoldingBase`, `HoldingCreate`, `Holding`
- `Transaction`, `TransactionCreate`
- `PortfolioStats`, `PortfolioDetailResponse`

**Valide:** Types, ranges, formats d'email, etc.

### **finance_service.py** (230+ lignes)
**Rôle:** Intégration Yahoo Finance pour données en temps réel

**Méthodes principales:**
```python
# Infos d'un actif
info = FinanceService.get_asset_info("AAPL")

# Prix actuel
price = FinanceService.get_current_price("AAPL")

# Données historiques
history = FinanceService.get_historical_data("AAPL", period="1mo")

# Calcul stats portfolio
stats = FinanceService.calculate_portfolio_stats(holdings_data)
```

### **config.py** (30 lignes)
**Rôle:** Configuration chargée depuis .env

**Variables:**
- `DATABASE_URL` - Chaîne de connexion DB
- `DEBUG` - Mode développement
- `ANTHROPIC_API_KEY` - Clé Claude (Phase 3)
- `NEWSAPI_KEY` - Clé NewsAPI (Phase 2)

### **requirements.txt** (11 packages)
```
fastapi              # Framework API
uvicorn              # Serveur ASGI
sqlalchemy           # ORM
pydantic             # Validation
yfinance             # Finance API
aiohttp              # Requêtes async
requests             # HTTP
python-dateutil      # Dates
psycopg2-binary      # PostgreSQL driver
```

### **Dockerfile**
**Rôle:** Container Docker pour production

**Build:** `docker build -t investor-ai-backend .`
**Run:** `docker run -p 8000:8000 investor-ai-backend`
