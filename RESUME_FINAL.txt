## 🌐 API REST (15+ Endpoints)

Tous accessibles à: **http://localhost:8000/docs**

```bash
# Ajouter un actif
POST /api/assets/add?symbol=AAPL

# Voir portfolio
GET /api/portfolio

# Ajouter position
POST /api/holdings/add?asset_id=1&quantity=10&avgPrice=143.50

# Historique prix
GET /api/assets/AAPL/history?period=1mo
```

Documentation Swagger avec exemples interactifs à: `http://localhost:8000/docs`

## 🔧 Technologie Utilisée

**Backend:**
- FastAPI - Framework API moderne et rapide
- SQLAlchemy - ORM pour base de données
- Pydantic - Validation de données
- yfinance - Récupération prix Yahoo Finance
- Uvicorn - Serveur ASGI

**Frontend:**
- Next.js - Framework React moderne
- React 18 - UI library
- Tailwind CSS - Styling
- Axios - Client HTTP
- Recharts - Graphiques (futur)

**Database:**
- SQLite - Défaut (local et simple)
- PostgreSQL - Option production

**Hosting (optionnel):**
- Vercel - Frontend (gratuit)
- Render/Railway - Backend (gratuit tier)
